# Shoes Store

This is a **Shoes Store** project, created using **HTML**, **CSS**, and **JavaScript**. The project simulates an online shoe store where users can browse different shoes, view product details, and interact with the page using basic JavaScript functionality.

You can view the live demo of the project at [Shoes Store](https://shoes-store-nu-red.vercel.app/#About).

---

## Features

- **Product Display**: Showcases different shoes with images, names, and descriptions.
- **Interactive**: Includes JavaScript to manage user interactions like adding items to the cart (if applicable).
- **Responsive Design**: Designed to be mobile-friendly with a clean, modern layout.
- **User-Friendly Navigation**: Easy-to-use interface for browsing shoes and learning more about the store.

---

## How to View the Project

1. Clone this repository:
   ```bash
   git clone git@github.com:nfoughal/shoes-store.git
   ```

2. Navigate into the project directory:
   ```bash
   cd shoes-store
   ```

3. Open `index.html` in your browser to view the project:
   ```bash
   open index.html
   ```
